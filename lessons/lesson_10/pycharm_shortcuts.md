# Урок 10. Горячие клавиши PyCharm

25 команд для работы с Python-кодом и домашними заданиями. Сочетания приведены для стандартных схем Windows/Linux и macOS. На Mac ⌘ — Command, ⌥ — Option, ⌃ — Control, ⇧ — Shift.

| № | Действие | Windows / Linux | macOS |
|---|---|---|---|
| 1 | Найти файл, символ или команду (Search Everywhere) | Дважды `Shift` | Дважды `⇧` |
| 2 | Найти команду IDE по названию (Find Action) | `Ctrl+Shift+A` | `⇧⌘A` |
| 3 | Найти текст в текущем файле | `Ctrl+F` | `⌘F` |
| 4 | Заменить текст в текущем файле | `Ctrl+R` | `⌘R` |
| 5 | Найти текст по проекту | `Ctrl+Shift+F` | `⇧⌘F` |
| 6 | Открыть список недавних файлов | `Ctrl+E` | `⌘E` |
| 7 | Перейти к объявлению функции, класса или переменной | `Ctrl+B` | `⌘B` |
| 8 | Найти места, где используется символ | `Alt+F7` | `⌥F7` |
| 9 | Показать варианты автодополнения | `Ctrl+Space` | `⌃Space` |
| 10 | Показать параметры функции внутри скобок вызова | `Ctrl+P` | `⌘P` |
| 11 | Показать быстрые исправления, например добавить импорт | `Alt+Enter` | `⌥Enter` |
| 12 | Добавить или убрать комментарий `#` у строки или выделенных строк | `Ctrl+/` | `⌘/` |
| 13 | Дублировать строку или выделенный фрагмент | `Ctrl+D` | `⌘D` |
| 14 | Отформатировать код в файле или выделенном фрагменте | `Ctrl+Alt+L` | `⌥⌘L` |
| 15 | Упорядочить импорты и убрать неиспользуемые | `Ctrl+Alt+O` | `⌃⌥O` |
| 16 | Переименовать символ и обновить его использования | `Shift+F6` | `⇧F6` |
| 17 | Перейти к следующей подсвеченной проблеме | `F2` | `F2` |
| 18 | Запустить текущую конфигурацию | `Shift+F10` | `⌃R` |
| 19 | Запустить текущую конфигурацию в отладчике | `Shift+F9` | `⌃D` |
| 20 | Поставить или снять точку останова на строке | `Ctrl+F8` | `⌘F8` |
| 21 | Выполнить строку без захода в вызванную функцию (Step Over) | `F8` | `F8` |
| 22 | Зайти в вызванную функцию (Step Into) | `F7` | `F7` |
| 23 | Продолжить выполнение до следующей точки останова или конца программы | `F9` | `⌥⌘R` |
| 24 | Открыть окно коммита Git | `Ctrl+K` | `⌘K` |
| 25 | Открыть окно отправки коммитов (Push) | `Ctrl+Shift+K` | `⇧⌘K` |

**Попробуй на уроке:** поставь точку останова перед вызовом функции, запусти отладчик и сравни `F7` с `F8`. Для первого запуска файла выбери **Run** в его контекстном меню и проверь, что в панели запуска выбрана нужная конфигурация.

Если сочетание не срабатывает, проверь **Settings → Keymap**: сочетания зависят от выбранной схемы и могут конфликтовать с системными. На ноутбуке для клавиш `F1`–`F12` иногда нужно удерживать `Fn`.

Источники JetBrains: [справка PyCharm](https://www.jetbrains.com/help/pycharm/mastering-keyboard-shortcuts.html), [схема Windows/Linux](https://resources.jetbrains.com/storage/products/pycharm/docs/PyCharm_ReferenceCard.pdf), [схема macOS](https://resources.jetbrains.com/storage/products/pycharm/docs/PyCharm_ReferenceCard_mac.pdf).
