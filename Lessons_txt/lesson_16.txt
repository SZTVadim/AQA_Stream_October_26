Слайд 1 — Классы в Python: как оживить код с помощью классов и объектов
Классы в Python помогают организовать программу: собрать данные и действия вместе и использовать
этот код многократно для создания похожих объектов.

Для чего использовать классы:
- объединять данные и функции, которые относятся друг к другу
- структурировать программу, делать её проще для понимания
- применять один шаблон для создания многих похожих объектов

Иначе говоря: классы — это готовые заготовки для объектов. По одному шаблону можно сделать
много экземпляров, как по одной выкройке можно сшить много одинаковых вещей.

Слайд 2 — Что такое класс в Python
Класс — это описание того, как создавать объекты. В нём указано, какие данные хранятся и
какие действия можно выполнять.

Объяснение через пример:
Если класс — это инструкция по сборке мебели, то объект — это собранная мебель. По одной
инструкции можно собрать несколько шкафов одинаковой конструкции, но они могут отличаться
материалом, цветом, наполнением.

В классе определяется:
- что будет храниться внутри объекта (данные, атрибуты)
- что объект умеет делать (функции, операции)

Объект — это конкретная вещь, созданная по описанию класса, со своими значениями.

Пример:
    class Dog:  # Класс (чертёж)
        pass
    
    my_dog = Dog()  # Объект (конкретная собака по чертежу)

Слайд 3 — Элементы класса
В классе есть три главных части, которые задают, как объект устроен и что он умеет.

Конструктор (__init__):
Особый метод, запускающийся сам при появлении нового объекта. Используется, чтобы задать
первоначальные значения и подготовить объект к использованию.

Атрибуты (свойства):
Переменные, которые содержат информацию об объекте. Хранят его характеристики. К примеру,
в классе "Собака" могут быть поля: имя собаки, сколько ей лет, какой породы.

Методы:
Функции класса, показывающие, что объект способен выполнять. Они используют данные объекта
и могут их изменять или возвращать как результат.

Кратко:
- Конструктор настраивает объект при его создании
- Поля хранят информацию об объекте
- Методы описывают, что объект умеет делать

Пример структуры:
    class Car:
        def __init__(self, brand, model):  # Конструктор
            self.brand = brand              # Поле
            self.model = model             # Поле
        
        def start(self):                    # Метод
            return f"{self.brand} заведена"

Слайд 4 — Экземпляр класса: что это такое
Экземпляр класса — это реальный объект, который был создан по описанию класса. Это конкретная
вещь, сделанная по шаблону.

Механизм работы:
Создавая объект на основе класса, вы получаете экземпляр. У каждого экземпляра свои значения,
но все они построены по одной схеме, описанной в классе.

Для понимания:
- Класс "Автомобиль" — это идея, общее представление об автомобиле
- Объект "Моя машина" — это реальный автомобиль со своим цветом, номером, маркой

Основные моменты:
- Класс — это идея, план, описание
- Объект — это конкретная вещь, сделанная по этому плану
- По одному классу можно сделать много разных объектов
- Все объекты независимы друг от друга, у каждого свои данные

Пример:
    class Person:
        def __init__(self, name):
            self.name = name
    
    person1 = Person("Анна")  # Экземпляр 1
    person2 = Person("Иван")  # Экземпляр 2
    # Оба объекта созданы по одному классу, но имеют разные имена

Слайд 5 — Простой пример: класс и объект
Рассмотрим полный пример: создадим класс "Собака" и несколько объектов этого класса.

Класс — это схема или инструкция. Объект — это готовый результат, полученный по этой схеме.

Пример:
    # Класс (чертёж) собаки
    class Собака:
        # Конструктор - метод, который вызывается при создании новой собаки
        def __init__(self, имя, возраст):
            self.имя = имя      # Поле (свойство) имени
            self.возраст = возраст  # Поле (свойство) возраста
        
        # Метод (действие), которое может выполнять собака
        def лаять(self):
            return f"{self.имя} говорит: Гав-гав!"
        
        # Ещё один метод
        def представиться(self):
            return f"Я {self.имя}, мне {self.возраст} лет"
    
    # Создаём объекты (конкретные собаки) по чертежу класса
    собака1 = Собака("Бобик", 3)
    собака2 = Собака("Шарик", 5)
    
    # Используем методы объектов
    print(собака1.лаять())        # Бобик говорит: Гав-гав!
    print(собака2.представиться()) # Я Шарик, мне 5 лет

Что происходит:
1. Определяем класс Собака с методом __init__, полями (имя, возраст) и методами (лаять, представиться)
2. Делаем два объекта: собака1 и собака2 с разными именами и возрастами
3. Вызываем методы у каждого объекта — каждый метод работает со своими данными конкретного объекта

Слайд 6 — Что такое __init__
__init__ — это особый метод в Python, запускающийся сам при появлении нового объекта. Также
его называют конструктором или инициализатором.

Механизм:
При создании объекта (например, dog = Dog("Бобик", 3)) Python сам запускает __init__ нужного
класса. Вам не нужно вызывать его самостоятельно — Python сделает это за вас.

Время вызова:
Автоматически! Сразу при создании объекта, как только объект появился, но ещё до того, как
он будет передан вам.

Назначение:
- задать начальные значения для полей объекта
- подготовить объект к дальнейшей работе
- принять параметры, которые передаются при создании объекта

Важно:
- Название метода должно быть точно __init__ (с двумя подчёркиваниями с каждой стороны)
- Первый параметр всегда self (ссылка на объект)
- Метод не должен возвращать значение (или возвращает None)

Пример:
    class Car:
        def __init__(self, brand, model):
            self.brand = brand
            self.model = model
            print(f"Создана машина {brand} {model}")
    
    car = Car("Toyota", "Camry")  # Автоматически вызывается __init__
    # Выведет: Создана машина Toyota Camry

Слайд 7 — Простая аналогия для понимания __init__
Для понимания работы __init__ подойдёт простая аналогия.

Аналогия с анкетой:
Класс — это бланк анкеты для устройства на работу, а __init__ — это заполнение этого бланка
при оформлении нового сотрудника.

Последовательность:
1. Создаём сотрудника: employee = Employee("Иван", "менеджер")
2. Автоматически заполняется анкета: запускается __init__, он записывает имя и должность
3. Готово: у сотрудника есть имя и должность, можно начинать работу

Что происходит внутри:
- Когда пишется Employee("Иван", "менеджер"), Python создаёт пустой объект
- Затем сам запускает __init__ и передаёт туда "Иван" и "менеджер"
- __init__ записывает эти данные в поля объекта
- Объект готов к использованию

Главное: __init__ вызывается автоматически, не нужно его вызывать вручную. Вы просто
создаёте объект, а Python сам вызывает __init__ "за сценой".

Слайд 8 — Зачем нужен __init__
__init__ решает несколько задач при создании объекта.

Задание начальных значений:
Устанавливаем первоначальные характеристики объекта. К примеру, при создании автомобиля сразу
указываем его марку и модель.

Подготовка к работе:
Делаем необходимые настройки. Можно, например, установить счётчики в нуль, подключиться к базе
данных, открыть нужные файлы и прочее.

Получение параметров:
Принимаем данные, которые нужны для создания конкретного объекта. Эти параметры передаются при
создании и применяются для настройки начального состояния объекта.

Что представляет собой __init__:
- Метод, запускающийся сам при создании объекта
- Используется для первоначальной настройки объекта
- Не нужно вызывать вручную (Python делает это сам)
- Позволяет передавать параметры при создании объекта

Без __init__:
Пришлось бы создавать объект, а затем вручную прописывать все его свойства. Это неудобно и
рискованно — можно что-то забыть и получить ошибку.

С __init__:
Объект появляется уже настроенным, все необходимые данные задаются автоматически.

Слайд 9 — Что такое self
self — это указатель на текущий объект. Благодаря ему класс "знает", с каким конкретно
экземпляром он работает в данный момент.

Объяснение простыми словами:
При вызове метода у объекта Python сам подставляет этот объект в качестве первого аргумента
self. Метод благодаря этому понимает, с каким объектом ему нужно работать.

Пример:
    class Car:
        def __init__(self, brand, model):
            self.brand = brand    # self.brand относится к объекту car1
            self.model = model    # self.model относится к объекту car1
    
    car1 = Car("Toyota", "Camry")
    # Когда создаётся car1, self внутри __init__ указывает на car1
    # Поэтому self.brand и self.model относятся именно к car1

Важные моменты:
- self подставляется автоматически при вызове метода — не нужно передавать его самим
- Имя self — это общепринятое соглашение (можно назвать иначе, но лучше так)
- self всегда стоит первым параметром в методах класса
- Через self можно получить доступ к полям и методам текущего объекта

Зачем нужен self:
Без self метод не понимал бы, с каким объектом работать. Если есть два объекта одного класса,
self помогает каждому методу работать со своим объектом и не путать их между собой.

Пример:
    car1 = Car("Toyota", "Camry")
    car2 = Car("Honda", "Civic")
    # Когда вызывается car1.start(), self указывает на car1
    # Когда вызывается car2.start(), self указывает на car2
