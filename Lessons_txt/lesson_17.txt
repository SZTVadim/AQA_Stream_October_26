Слайд 2 — Задание 1: Класс для тестовых данных пользователя
Задача:
Создайте класс TestUser для хранения и работы с данными пользователя в тестах. Класс должен
позволять создавать пользователей с различными данными и валидировать их корректность.

Требования:
1. Класс должен иметь конструктор __init__, который принимает:
   - username (обязательный)
   - email (обязательный)
   - password (обязательный)
   - age (опциональный, по умолчанию None)
   - is_active (опциональный, по умолчанию True)

2. Добавьте метод validate_email(), который проверяет, что email содержит символ "@"
   и возвращает True/False

3. Добавьте метод validate_password(), который проверяет, что пароль содержит минимум
   8 символов и возвращает True/False

4. Добавьте метод get_user_info(), который возвращает словарь со всеми данными пользователя

5. Добавьте метод is_adult(), который возвращает True, если возраст >= 18, иначе False
   (если возраст не указан, возвращает None)

Пример использования:
    user1 = TestUser("john_doe", "john@example.com", "securepass123", 25)
    print(user1.validate_email())      # True
    print(user1.validate_password())   # True
    print(user1.is_adult())            # True
    print(user1.get_user_info())       # {'username': 'john_doe', ...}

Решение:
    class TestUser:
        def __init__(self, username, email, password, age=None, is_active=True):
            self.username = username
            self.email = email
            self.password = password
            self.age = age
            self.is_active = is_active
        
        def validate_email(self):
            """Проверяет корректность email"""
            return "@" in self.email
        
        def validate_password(self):
            """Проверяет, что пароль содержит минимум 8 символов"""
            return len(self.password) >= 8
        
        def get_user_info(self):
            """Возвращает словарь с данными пользователя"""
            return {
                "username": self.username,
                "email": self.email,
                "password": self.password,
                "age": self.age,
                "is_active": self.is_active
            }
        
        def is_adult(self):
            """Проверяет, является ли пользователь совершеннолетним"""
            if self.age is None:
                return None
            return self.age >= 18

Слайд 3 — Задание 2: Класс для логирования результатов тестов
Задача:
Создайте класс TestLogger для логирования результатов выполнения тестов. Класс должен
накапливать информацию о тестах и предоставлять статистику.

Требования:
1. Конструктор __init__ должен инициализировать:
   - пустой список для хранения результатов тестов
   - счётчик пройденных тестов (passed)
   - счётчик проваленных тестов (failed)

2. Метод log_test(test_name, status) должен:
   - принимать название теста и статус ("passed" или "failed")
   - добавлять результат в список в формате словаря: {"test_name": ..., "status": ...}
   - увеличивать соответствующий счётчик

3. Метод get_statistics() должен возвращать словарь:
   - total_tests: общее количество тестов
   - passed: количество пройденных
   - failed: количество проваленных
   - success_rate: процент успешных тестов (округлить до 2 знаков)

4. Метод get_failed_tests() должен возвращать список названий проваленных тестов

5. Метод clear() должен очищать все результаты и сбрасывать счётчики

Пример использования:
    logger = TestLogger()
    logger.log_test("test_login", "passed")
    logger.log_test("test_registration", "failed")
    logger.log_test("test_logout", "passed")
    
    print(logger.get_statistics())
    # {'total_tests': 3, 'passed': 2, 'failed': 1, 'success_rate': 66.67}
    
    print(logger.get_failed_tests())  # ['test_registration']

Решение:
    class TestLogger:
        def __init__(self):
            self.test_results = []
            self.passed = 0
            self.failed = 0
        
        def log_test(self, test_name, status):
            """Логирует результат выполнения теста"""
            if status not in ["passed", "failed"]:
                raise ValueError("Status must be 'passed' or 'failed'")
            
            self.test_results.append({
                "test_name": test_name,
                "status": status
            })
            
            if status == "passed":
                self.passed += 1
            else:
                self.failed += 1
        
        def get_statistics(self):
            """Возвращает статистику по тестам"""
            total = len(self.test_results)
            if total == 0:
                return {
                    "total_tests": 0,
                    "passed": 0,
                    "failed": 0,
                    "success_rate": 0.0
                }
            
            success_rate = round((self.passed / total) * 100, 2)
            return {
                "total_tests": total,
                "passed": self.passed,
                "failed": self.failed,
                "success_rate": success_rate
            }
        
        def get_failed_tests(self):
            """Возвращает список названий проваленных тестов"""
            return [result["test_name"] for result in self.test_results 
                    if result["status"] == "failed"]
        
        def clear(self):
            """Очищает все результаты и сбрасывает счётчики"""
            self.test_results = []
            self.passed = 0
            self.failed = 0

Пример 3: Комбинированное использование TestUser и TestLogger
    # Создание пользователей для тестирования
    test_users = [
        TestUser("admin", "admin@test.com", "admin123456", 30),
        TestUser("user1", "user1@test.com", "pass123", 17),
        TestUser("user2", "invalid-email", "weak", 25),
        TestUser("user3", "user3@test.com", "strongpassword", None)
    ]
    
    # Создание логгера для записи результатов валидации
    validation_logger = TestLogger()
    
    # Валидация каждого пользователя и логирование результатов
    for i, user in enumerate(test_users, 1):
        test_name = f"test_user{i}_validation"
        
        # Проверка валидности данных
        email_valid = user.validate_email()
        password_valid = user.validate_password()
        is_adult = user.is_adult()
        
        # Логирование результата валидации
        if email_valid and password_valid:
            if is_adult is None:
                validation_logger.log_test(f"{test_name}_age_check", "failed")
            elif is_adult:
                validation_logger.log_test(test_name, "passed")
            else:
                validation_logger.log_test(f"{test_name}_minor", "passed")
        else:
            validation_logger.log_test(test_name, "failed")
        
        # Вывод информации о пользователе
        print(f"\nПользователь {i}: {user.username}")
        print(f"  Email валиден: {email_valid}")
        print(f"  Пароль валиден: {password_valid}")
        print(f"  Совершеннолетний: {is_adult}")
    
    # Итоговая статистика валидации
    print("\n=== Итоговая статистика валидации ===")
    final_stats = validation_logger.get_statistics()
    print(f"Всего проверок: {final_stats['total_tests']}")
    print(f"Успешных: {final_stats['passed']}")
    print(f"Проваленных: {final_stats['failed']}")
    print(f"Процент успеха: {final_stats['success_rate']}%")
    
    # Список проваленных проверок
    failed_validations = validation_logger.get_failed_tests()
    if failed_validations:
        print(f"\nПроваленные проверки: {failed_validations}")
