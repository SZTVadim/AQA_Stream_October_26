Слайд 1 — Работа с datetime Python для автотестировщиков
В тестировании часто нужно работать со временем. Например, проверять даты создания заказов, логи с временными метками,
таймауты при ожидании элементов на странице, время выполнения тестов. Модуль datetime в Python помогает легко работать
с датами и временем.

Пример:
    from datetime import datetime
    now = datetime.now()
    print(f"Тест запущен: {now}")

Слайд 2 — Введение
datetime — это встроенный модуль Python, который уже есть в стандартной библиотеке. Его не нужно устанавливать отдельно.
Он помогает работать с датами и временем в тестах.

Зачем нужен datetime в тестировании:
- проверять время выполнения тестов (сколько времени заняла проверка)
- работать с датами в формах (например, выбрать дату в календаре)
- добавлять временные метки в логи (чтобы знать, когда что произошло)
- проверять таймауты и ожидания (например, ждать элемент 10 секунд)
- сравнивать даты (проверить, что заказ создан после определённой даты)

Пример:
    from datetime import datetime
    start = datetime.now()
    # здесь выполняем тестовые действия
    end = datetime.now()
    print(f"Тест выполнен за: {end - start}")

Слайд 3 — Модуль datetime
Чтобы использовать datetime, его нужно импортировать. Есть несколько способов импорта — выбирайте, какой удобнее.

Первый способ — импортировать всё нужное сразу:
    from datetime import datetime, date, time, timedelta

Второй способ — импортировать весь модуль:
    import datetime

Третий способ — импортировать с коротким именем (алиас):
    import datetime as dt

Пример:
    from datetime import datetime
    now = datetime.now()
    print(now)

Слайд 4 — Основные классы
В модуле datetime есть несколько классов для разных задач. Каждый класс отвечает за свою часть работы со временем.

datetime — самый универсальный класс. Он хранит и дату, и время вместе (год, месяц, день, час, минута, секунда).
date — класс только для даты (год, месяц, день). Время не учитывается.
time — класс только для времени (часы, минуты, секунды, микросекунды). Дата не учитывается.
timedelta — класс для разницы между датами или времени. Полезен, когда нужно прибавить или вычесть время.

Пример:
    from datetime import datetime, date, time, timedelta
    dt = datetime.now()          # дата и время
    d = date.today()             # только дата
    t = time(15, 30, 0)          # только время
    delta = timedelta(days=7)    # разница во времени

Слайд 5 — Класс datetime
Класс datetime объединяет дату и время в один объект. Это самый часто используемый класс в тестах.

Создать объект datetime можно разными способами:
1. Получить текущее время — datetime.now()
2. Указать конкретную дату и время — datetime(год, месяц, день, час, минута, секунда)

Пример:
    from datetime import datetime
    
    # Текущее время
    now = datetime.now()
    print(now)  # 2024-12-20 15:30:45.123456
    
    # Конкретная дата и время
    specific = datetime(2024, 12, 25, 15, 30, 0)
    print(specific)  # 2024-12-25 15:30:00
    
    # Можно указать только дату, время будет 00:00:00
    only_date = datetime(2024, 1, 1)
    print(only_date)  # 2024-01-01 00:00:00

Слайд 6 — Проверки времени
В тестах часто нужно проверить, сколько времени заняла операция, или сравнить, что дата правильная.

Как проверить время выполнения:
1. Записываем время начала — start_time = datetime.now()
2. Выполняем операцию (например, ждём загрузку страницы)
3. Записываем время окончания — end_time = datetime.now()
4. Вычисляем разницу — duration = end_time - start_time

Пример:
    from datetime import datetime
    import time  # для имитации долгой операции
    
    start_time = datetime.now()
    time.sleep(2)  # имитируем операцию, которая длится 2 секунды
    end_time = datetime.now()
    
    duration = end_time - start_time
    print(f"Операция заняла: {duration.total_seconds()} секунд")
    print(f"В миллисекундах: {duration.total_seconds() * 1000}")

Слайд 7 — Timestamp
Timestamp (временная метка) — это количество секунд, прошедших с 1 января 1970 года 00:00:00 UTC. Это стандартный
способ хранения времени в компьютерах.

Зачем нужен timestamp:
- удобно для сравнения дат (просто сравниваем числа)
- используется в базах данных
- нужен для API (часто даты передаются как timestamp)
- компактное хранение времени

Как преобразовать datetime в timestamp:
- now.timestamp() — получаем timestamp из datetime
- datetime.fromtimestamp(число) — получаем datetime из timestamp

шпаргалка сайт для преобразования https://docs.python.org/3/library/datetime.html

Пример:
    from datetime import datetime
    
    # Получаем текущее время
    now = datetime.now()
    print(f"Время: {now}")
    
    # Преобразуем в timestamp
    timestamp = now.timestamp()
    print(f"Timestamp: {timestamp}")
    
    # Преобразуем обратно из timestamp в datetime
    from_timestamp = datetime.fromtimestamp(timestamp)
    print(f"Из timestamp: {from_timestamp}")
